# Binary Exponentiation (Completed ✅)

Learned

* Why O(n) recursion fails
* Why constraints matter
* Binary Exponentiation
* Modulo arithmetic
* Fast Power

Formula

Even

```text
x^n = (x²)^(n/2)
```

Odd

```text
x^n = x × (x²)^((n−1)/2)
```

Complexity

```text
TC = O(log n)

SC = O(log n)
```

# Count Good Numbers (Completed ✅)

Observation

```text
Answer

=

5^(Even Positions)

×

4^(Odd Positions)
```

where

```cpp
even = (n+1)/2

odd = n/2
```

Then compute

```cpp
powMOD(5,even)

powMOD(4,odd)
```

using Binary Exponentiation.

# Important Learnings

## Modulo

Always

```cpp
1LL * a * b % MOD
```

Never

```cpp
a*b%MOD
```

if overflow possible.

---

## INT_MIN Edge Case

For Leetcode 50

Never

```cpp
-n
```

Instead

```cpp
long long N=n;
N=-N;
```

---

## Binary Exponentiation

Preferred

```cpp
return power(x*x,n/2);
```

Odd

```cpp
return x*power(x*x,(n-1)/2);
```
